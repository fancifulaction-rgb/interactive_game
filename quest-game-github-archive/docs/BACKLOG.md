# Бэклог Quest Game

Идеи и доработки для платформы **командных квестов на корпоративных мероприятиях** (аудитория ~20–60 лет).

## Админка и безопасность

- [ ] Смена пароля администратора без отображения в открытом виде
- [ ] Регистрация администратора через e-mail
- [ ] Редактирование настроек категории «Время» в админ-панели

## Игра и UX

- [ ] Код игры: 6 символов + буквы
- [ ] Комната ожидания — общий старт, когда все команды зарегистрировались
- [ ] Общая пауза игры для всех команд
- [ ] Оповещения всем игрокам (расширить текущую систему сообщений)
- [ ] Отключить доступ к таблице результатов во время игры
- [ ] После финиша: либо таблица результатов, либо только поздравление (настройка)
- [ ] Дата создания квеста в списке игр
- [ ] Уточнить/упростить «тип вопроса» в редакторе

## Контент и оформление

- [ ] Логотип и картинки на приветственной странице (частично есть)
- [ ] Темы/скины: плавный фон (снег и т.п.), без налезания на блок вопроса
- [ ] Красивое табло результатов, фото команд в результатах

## Механики

- [ ] Множественные варианты ответов (см. [guides/MULTIPLE_ANSWERS.md](guides/MULTIPLE_ANSWERS.md))
- [ ] Подсказки и штрафы — проверить пропадающие подсказки
- [ ] Пересмотреть систему штрафных баллов
- [ ] Проверить влияние паузы на итоговый счёт и формулу

## Инфраструктура

- [ ] PWA: manifest + service worker
- [ ] Деплой фронта (Vercel / Netlify / свой хостинг)
- [ ] Убрать service role с клиента (использовать Edge Functions для админ-операций)
