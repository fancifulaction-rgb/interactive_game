# Ручное QA — чеклист с отметками

Документ для **вашего** прогона в браузере. Отмечайте статус и пишите, что видите — агент потом прочитает файл, закроет пройденные пункты в `TEST_BACKLOG.md` / `BUGS_FOUND.md` и исправит провалы.

**Связанные документы:** [TESTING.md](TESTING.md) · [TEST_BACKLOG.md](TEST_BACKLOG.md) · [BUG_AUDIT_HANDOFF.md](BUG_AUDIT_HANDOFF.md)

---

## Как пользоваться

1. Перед прогоном заполните блок **«Сессия тестирования»** ниже.
2. Идите по разделам **A → H** (можно не по порядку).
3. В каждом тесте замените строку **«Статус тестера»** на одно из значений:

   | Маркер | Значение |
   |--------|----------|
   | `⬜` | ещё не проверял |
   | `✅` | пройден — всё как в «Ожидание» |
   | `❌` | провал — опишите в «Что вижу» |
   | `⏸` | пропущен (нет телефона, времени и т.п.) |
   | `🔁` | нужна перепроверка после правки агента |

4. В **«Что вижу / комментарий»** пишите свободно: скриншот не обязателен, достаточно «зависло 30 с», «кнопка серая», «на iPhone Safari …».
5. Когда закончите блок или весь файл — напишите агенту: *«Проверь @docs/MANUAL_QA_CHECKLIST.md и закрой пройденное / почини ❌»*.

**Не коммитьте** `.env` и секреты. URL dev-сервера и код игры — можно.
