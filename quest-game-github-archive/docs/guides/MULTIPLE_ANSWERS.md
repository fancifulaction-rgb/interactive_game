# Руководство по множественным ответам в квест-приложении

## Обзор новой функциональности

Теперь вы можете создавать вопросы с разным количеством вариантов ответов - от 1 до 6. Система автоматически адаптирует игровой интерфейс под каждый вопрос.

## Типы вопросов

### 1. Текстовый ввод (1 вариант)
- **Использование**: Вопросы со свободным ответом
- **Отображение**: Текстовое поле для ввода
- **Пример**: "Столица России?" → Ответ: "Москва"

### 2. Выбор из вариантов (2-6 вариантов)
- **Использование**: Вопросы с фиксированными вариантами ответов
- **Отображение**: Чекбоксы для выбора одного или нескольких вариантов
- **Примеры**:
  - 2 варианта: "Верно или неверно?"
  - 4 варианта: "Какие города в России?"
  - 6 вариантов: "Выберите чётные числа"

## Для администраторов: Создание вопросов

### Шаг 1: Выбор количества ответов

В форме создания вопроса выберите количество вариантов:
- **1 - Текстовый ввод**: Игрок будет вводить ответ вручную
- **2-6 вариантов**: Игрок будет выбирать из предложенных вариантов

### Шаг 2: Заполнение данных

#### Для текстового ввода (1 вариант):
1. Введите текст вопроса
2. Введите правильный ответ в поле "Правильный ответ"
3. Сохраните вопрос

#### Для выбора из вариантов (2-6):
1. Введите текст вопроса
2. Заполните все варианты ответов
3. **Отметьте чекбоксы** слева от правильных ответов
4. Внизу отобразится количество правильных ответов
5. Сохраните вопрос

### Валидация

Система проверит:
- ✓ Все варианты заполнены
- ✓ Минимум 1 правильный ответ отмечен
- ✓ Текст вопроса не пустой

Без выполнения этих условий сохранение невозможно.

## Для игроков: Прохождение квеста

### Текстовый вопрос
1. Прочитайте вопрос
2. Введите ответ в текстовое поле
3. Нажмите "Отправить ответ"

**Подсказка**: Регистр букв не важен - "Москва" и "москва" считаются одинаковыми ответами.

### Вопрос с вариантами
1. Прочитайте вопрос
2. Отметьте один или несколько вариантов чекбоксами
3. Нажмите "Отправить ответ"

**Важно**: Вы можете выбрать несколько вариантов, если считаете что правильных ответов больше одного.

## Система начисления баллов

### Текстовый ввод
- **Правильный ответ**: 100% базовых баллов
- **Неправильный ответ**: 0 баллов

### Множественный выбор

Система учитывает частичную правильность:

| Ваш выбор | Результат | Баллы |
|-----------|-----------|-------|
| Все правильные выбраны, неправильных нет | Полностью правильно | 100% |
| Часть правильных выбрана, неправильных нет | Частично правильно | 50% |
| Часть правильных выбрана, есть неправильные | Частично правильно | 30% |
| Только неправильные варианты | Неправильно | 0% |

### Примеры

**Вопрос**: "Какие из этих городов в России?"
- Варианты: Москва, Лондон, Санкт-Петербург, Париж
- Правильные: Москва, Санкт-Петербург

**Сценарии**:
1. Выбрали: Москва, Санкт-Петербург → 100% баллов
2. Выбрали: Москва → 50% баллов (не выбрали СПб, но нет неправильных)
3. Выбрали: Москва, Лондон → 30% баллов (есть правильный, но есть и неправильный)
4. Выбрали: Лондон, Париж → 0% баллов (только неправильные)

## Дополнительные факторы баллов

Базовые баллы умножаются на:
- **Коэффициент сложности**: Легкий (1.0), Средний (1.5), Сложный (2.0)
- **Бонус за скорость**: +1 очко за каждые 10 секунд до конца времени
- **Штраф за подсказки**: -10% за каждую использованную подсказку

## Обратная совместимость

Все существующие вопросы автоматически конвертированы в новый формат:
- Старые вопросы стали вопросами с "1 вариантом" (текстовый ввод)
- Все данные сохранены без потерь
- Вы можете редактировать старые вопросы как обычно

## Советы по созданию вопросов

### Когда использовать текстовый ввод (1 вариант):
- Вопросы на знание фактов: "В каком году...?"
- Математические задачи: "2 + 2 = ?"
- Открытые вопросы: "Назовите столицу..."

### Когда использовать множественный выбор (2-6 вариантов):
- Проверка знаний с несколькими правильными ответами
- Вопросы "правда/ложь" (2 варианта)
- Классификация: "Какие из этих фруктов?"
- Сложные вопросы с частичным зачётом баллов

### Рекомендации:
1. **Не делайте слишком очевидные варианты**: "Москва, Париж, ААА, БББ" - плохо
2. **Используйте похожие варианты**: "JavaScript, Java, Python, C++" - хорошо
3. **Количество правильных ответов**: Для 4 вариантов оптимально 1-2 правильных
4. **Формулировка**: Четко укажите "Выберите ВСЕ правильные" или "Выберите ОДИН"

## Технические детали

### База данных
Новые поля в таблице `questions`:
- `answer_count`: Количество вариантов (1-6)
- `answer`: Массив правильных ответов (JSON)
- `options`: Массив всех вариантов (JSON)

### API
При сохранении ответа игрока:
```json
{
  "team_id": "uuid",
  "question_id": "uuid",
  "answer_text": "Москва, Санкт-Петербург",  // для множественного выбора через запятую
  "is_correct": true,
  "score": 150
}
```

## Часто задаваемые вопросы

**В: Можно ли изменить количество вариантов после создания вопроса?**
О: Да, просто измените значение в селекторе и заново заполните варианты.

**В: Что если игрок выберет больше вариантов чем нужно?**
О: Система учтет это при подсчёте баллов. Если среди выбранных есть неправильные - баллы снизятся.

**В: Можно ли создать вопрос с 1 вариантом но чтобы были чекбоксы?**
О: Нет, для 1 варианта всегда используется текстовое поле. Если нужны чекбоксы - выберите минимум 2 варианта.

**В: Регистр букв важен в текстовых ответах?**
О: Нет, "Москва", "москва", "МОСКВА" - все считаются правильными.

**В: Сколько максимум правильных ответов может быть?**
О: Любое количество от 1 до количества вариантов. Например, для 6 вариантов можно отметить все 6 как правильные.

## Поддержка

При возникновении проблем:
1. Проверьте что все поля заполнены
2. Убедитесь что отмечен минимум 1 правильный ответ
3. Попробуйте сохранить еще раз
4. Обратитесь к администратору системы
