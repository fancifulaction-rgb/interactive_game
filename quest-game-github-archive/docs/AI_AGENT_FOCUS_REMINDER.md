Твоя работа сейчас — Спринт 1 (ROADMAP): Edge deploy, RPC счёта, узкие SELECT, безопасность — НЕ PWA, НЕ AI, НЕ Socket.IO, пока владелец не выберет ID из каталога.

## Самопроверка сессии (сделай сейчас, кратко в ответе)

C) **Отклонения:** что начал делать вне спринта/каталога? Остановить или согласовать с владельцем.
D) **Риски:** нарушил ли очередь requestQueue, parallel Supabase, select('*'), service role во фронте?
E) **Git:** есть ли незакоммиченное? Нужен commit+push по завершении блока.

Если A пустой — остановись и согласуй задачу по ROADMAP, не придумывай фичу.

## Cursor Rules (уже в репозитории)

В корне workspace `g:\Code\quest-game\.cursor\rules\`:

| Файл | Режим | Назначение |
|------|-------|------------|
| `quest-game-focus.mdc` | `alwaysApply: true` | Фокус проекта, Спринт 1, ссылки на docs |
| `quest-game-player-network.mdc` | при открытии `src/lib/**`, GamePlay, … | Очередь и optimistic UI |

В Cursor: **Settings → Rules → Project Rules** — должны отображаться автоматически.
