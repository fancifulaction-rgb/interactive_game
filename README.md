# Quest Game

Платформа для **командных интерактивных квестов** на корпоративных и офлайн-мероприятиях.

## Репозиторий

| Путь | Содержимое |
|------|------------|
| [quest-game-github-archive/](quest-game-github-archive/) | Исходный код React + Supabase |
| [archive/backups/](archive/backups/) | Резервная копия БД Supabase |

## Быстрый старт

```bash
cd quest-game-github-archive
cp .env.example .env
npm install
npm run dev
```
